Performance Memory na Medeli AKX10

Performance Memory je Medelijev ekvivalent Yamaha Registration Memory: jedan gumb = cijeli setup za pjesmu. AKX10 nudi 8 slotova × 200 banaka, uz Lock i vezu s Q.S. / O.T.S.

Što se sprema

  • Voice-ovi na L, R1, R2, R3 (uključujući split točku)
  • Odabrani stil, tempo, transpozicija
  • Mixer (volume traka stila i ruku)
  • Efekti, EQ, Harmony / Arpeggiator / Slicer ako su uključeni
  • Phrase Pad odabir

Kako spremiti

  1. Složite pjesmu: stil, zvukovi, volume, efekti.
  2. Otvorite Performance Memory.
  3. Odaberite banku i prazan slot.
  4. Hold Save (ili Save na ekranu) i upišite ime pjesme.

Lock / Freeze

Lock sprječava da sljedeći Performance pregazi npr. transpoziciju ili stil dok mijenjate samo zvuk. Korisno kad u setu imate dvije pjesme u istom ritmu, a različite leadove.

Organizirajte banke po setlisti (Bank 1 = prvi set, Bank 2 = drugi). Q.S. Link držite uključen kad želite da O.T.S. prati Main A–D unutar iste pjesme.
